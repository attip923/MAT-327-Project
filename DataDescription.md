I got my dataset from Kaggle, searching for an EEG-related set, since Neuroscience is my field of interest. The dataset I chose was a set containing EEG data of confusion in 10 students each watching 10 MOOC videos. The dataset was created by Haohan Wang and the data is from around 2018. A question I would like to answer using this dataset is whether gender played a part in the level of confusion. Another question I would like to answer using this dataset is how big of a part did attention and calmness play in confusion for the students. One of the columns in the data set is Attention, and contains the EEG reading of the part of the brain that has to do with attention (or how long the student paid attention), which is quantitative. Another column is gender, which contains the gender of each student, and is qualitative data. A third column is Raw, which is the raw EEG signal, and is quantitative data. Finally, the last column I’ll be looking at is Mediation, which contains the level of calmness in the students, and is quantitative data.
